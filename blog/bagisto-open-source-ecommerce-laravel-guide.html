1. What is Bagisto?

Bagisto is a free, open-source eCommerce platform built on the Laravel PHP framework with a Vue.js-powered storefront. First released in 2018 by Webkul Software, it has grown into one of the most-starred eCommerce repositories on GitHub, with an active community of developers and an official marketplace of 400+ extensions.

3. How to Install Bagisto (Step-by-Step Guide)

Bagisto's installation follows standard Laravel conventions. Here's a production-ready setup on a modern Ubuntu VPS or local development environment.

System Requirements

  • PHP: 8.1 or higher (8.2 recommended)
  • Composer: 2.x
  • Database: MySQL 5.7+ or MariaDB 10.3+
  • Node.js: 16+ and npm/yarn
  • Web Server: Nginx or Apache with mod_rewrite

Installation Commands

# 1. Clone the Bagisto repository
git clone https://github.com/bagisto/bagisto.git
cd bagisto

# 2. Install PHP dependencies
composer install

# 3. Copy environment file and configure
cp .env.example .env

# 4. Edit .env with your DB credentials
# DB_HOST=127.0.0.1
# DB_DATABASE=bagisto
# DB_USERNAME=root
# DB_PASSWORD=your_password

# 5. Run the Bagisto installer (interactive CLI wizard)
php artisan bagisto:install

# 6. Install frontend dependencies and build assets
npm install
npm run build

# 7. Start the development server
php artisan serve
💡 Pro Tip:

The php artisan bagisto:install command is an interactive wizard that handles database migrations, seeding demo data, creating your admin account, and setting the base currency — all in one go. No manual SQL imports required.

5. Core Features That Make Bagisto Production-Ready

5.1 Multi-Channel & Multi-Store Architecture

Bagisto's concept of Channels lets you run multiple storefronts from a single admin — each with its own domain, theme, currency, and product catalog. This is perfect for businesses targeting different geographies or customer segments (e.g., a B2B wholesale channel and a B2C retail channel).

5.2 Multi-Currency & Multi-Locale

With native support for 130+ currencies and automatic exchange rate fetching, plus RTL language support (Arabic, Hebrew, Urdu), Bagisto is genuinely built for global commerce — not retrofitted for it.

5.3 Headless Commerce with REST & GraphQL APIs

Every core operation in Bagisto is exposed via a comprehensive API layer:

# Get all products
GET /api/v1/core/products

# Place an order
POST /api/v1/checkout/orders

# Get customer orders (authenticated)
GET /api/v1/customer/orders

# GraphQL — fetch featured products
POST /graphql
{
  products(filters: { featured: true }) {
    data { id name price }
  }
}

5.4 Payment Gateways (Including Indian Payment Methods)

  • Razorpay, PayU, CCAvenue (India-ready)
  • Stripe, PayPal (global)
  • Cash on Delivery, Bank Transfer (offline)
  • Custom payment gateway via package development

5.5 Shipping & Logistics

  • Shiprocket, Delhivery, FedEx integrations via marketplace
  • Flat-rate, free shipping, and table rate shipping methods built-in
  • Zone-based shipping rules per channel

6. Extending Bagisto: Building Custom Packages

Bagisto's modular architecture is built on Laravel Service Providers. Any custom feature — a loyalty rewards system, a custom tax rule engine, a B2B quote request module — becomes a standalone package that plugs into Bagisto without touching core files.

# Generate a new custom package scaffold
php artisan package:make Acme/LoyaltyRewards

# Package structure created:
# packages/Acme/LoyaltyRewards/
# ├── src/
# │   ├── Http/Controllers/
# │   ├── Models/
# │   ├── Repositories/
# │   └── Providers/LoyaltyRewardsServiceProvider.php
# ├── Resources/
# │   ├── views/
# │   ├── lang/
# │   └── assets/
# └── composer.json

Architecture Rule: Never modify Bagisto's core files. All customizations go in a named package under /packages/. This keeps your store upgradeable — you can pull the latest Bagisto release without overwriting your custom code.

8. Performance Optimization for Production Bagisto Stores

A slow eCommerce site bleeds revenue. Here are the performance optimizations the VitableTech team applies on every Bagisto production deployment:

# Cache configuration, routes, and views
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Enable OPcache in php.ini
opcache.enable=1
opcache.memory_consumption=256

# Optimize Composer autoloader
composer install --optimize-autoloader --no-dev

# Queue workers for async emails & notifications
php artisan queue:work --daemon

# Enable Redis for sessions & cache
# CACHE_DRIVER=redis
# SESSION_DRIVER=redis
# QUEUE_CONNECTION=redis
  • Use a CDN (Cloudflare or BunnyCDN) for all static assets and product images.
  • Enable Elasticsearch for large catalogs (5000+ products) to get instant search results.
  • Use Redis for cache, sessions, and queues to dramatically reduce MySQL load.
  • Image Optimization: Convert all product images to WebP using Bagisto's built-in image resizer.

9. Frequently Asked Questions About Bagisto

Is Bagisto truly free, even for commercial use?

Yes. Bagisto is licensed under the MIT License, which means you can use it for any commercial project without paying licensing fees. You only pay for your server and any premium extensions from the marketplace.

What are the server requirements for Bagisto?

PHP 8.1+, Composer, MySQL 5.7+, Node.js 16+, and Nginx or Apache. For production, we recommend at least 2 GB RAM. For high-traffic stores (10k+ daily visitors), 4 GB RAM with Redis and a separate database server.

Does Bagisto support multi-store and multi-currency?

Yes, natively. The "Channels" system in Bagisto lets you run unlimited storefronts from one admin panel, each with a unique domain, theme, currency, language, and product catalog. No plugin required.

How does Bagisto Cloud Hosting differ from self-hosting?

Bagisto Cloud is a fully managed service — the Bagisto team handles server provisioning, SSL, updates, backups, and scaling. Self-hosting gives you more control and lower cost at scale but requires DevOps expertise. VitableTech can help you set up either option.

Can I build a mobile app on top of Bagisto?

Absolutely. Bagisto's REST and GraphQL APIs are designed for headless commerce. You can build a React Native or Flutter mobile app that consumes Bagisto's APIs for product listing, cart, checkout, and order management — all without touching the PHP code.
